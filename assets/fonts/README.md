# Fonts

`Saira.ttf` is Saira (variable: weight 100–900, width 50–125; Copyright 2020 The Saira Project
Authors, SIL Open Font License 1.1, see `Saira-OFL.txt`), the interface face since 0.17: labels,
headings, buttons, numbers. Chinese falls back to Noto Sans SC.

`NotoSansSC.ttf` is Noto Sans SC (思源黑体, variable: weight 100–900; Copyright 2014-2021 Adobe,
SIL Open Font License 1.1, see `NotoSansSC-OFL.txt`), from
https://github.com/google/fonts/tree/main/ofl/notosanssc: the Chinese of the interface (bold
headings, the heaviest weight for big titles) and the reading font "黑体".

`LXGWWenKaiScreen.ttf` is the full LXGW WenKai Screen v1.522 (霞鹜文楷 屏幕阅读版, SIL Open
Font License 1.1, see `OFL.txt`), from https://github.com/lxgw/LxgwWenKai-Screen/releases: the
reading font when chosen in Settings.
`EndfieldByButan.ttf` is EndfieldByButan by 罗醭坦 (bilibili @罗醭坦), from
https://github.com/lhclbt/Endfield_Font: the in-world script of Arknights and Arknights: Endfield,
deciphered from the games (the script's design belongs to Hypergryph). Licensed CC BY-NC 4.0
(https://creativecommons.org/licenses/by-nc/4.0/): free to use with credit, not for commercial use.
It has Latin letters, digits and some punctuation only; the app uses it for decoration (the small
labels over headings and tabs; no `// ` before them, its slash is a solid square), never for text that has to be read.
