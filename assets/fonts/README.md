# Fonts

`Saira.ttf` is Saira (variable: weight 100–900, width 50–125; Copyright 2020 The Saira Project
Authors, SIL Open Font License 1.1, see `Saira-OFL.txt`), the interface face since 0.17: labels,
headings, buttons, numbers. Chinese falls back to the system sans.

`LXGWWenKaiScreen.ttf` is the full LXGW WenKai Screen v1.522 (霞鹜文楷 屏幕阅读版, SIL Open
Font License 1.1, see `OFL.txt`), from https://github.com/lxgw/LxgwWenKai-Screen/releases: the
reading font when chosen in Settings (the default reading font is the system sans).
`lxgw-wenkai/` holds the web fonts of the wiki reader.
