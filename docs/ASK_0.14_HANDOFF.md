## 6. 遗留问题

### 确定存在

1. **关键词扫描是检索里最慢的一段。** 手机上每个库 1.3–6.3 秒（并行的检索更慢）；Wiki 0.5–12 秒；剧情向量 0.08–0.2 秒；资料向量 0.13–0.66 秒。
   终末地的库小得多，耗时却和明日方舟接近，像是在同一个连接上排队（**没有查代码确认**）。
   入口：`SearchTool._rank` → `searchStoryLinesLike`（`lib/core/gamedata/story_line_search.dart`）。先确认是不是排队，再考虑各用各的只读连接或合并扫描。
2. **路径写短的出处被删**（§2 第 3 条）。
3. **拟定的检索词带资料种类的词和泛名字**（§2 第 4 条）。评测集上的命中是 25/29（带向量）。
4. **长整理题很贵。** “整理某人在主线第 9–15 章的主要行动”全程只用 `grep`（16 次）、没有 `read_story`，输入 27.8 万 token、100 秒；答案七章都有小节和出处。
5. **答案正文偶尔提到“知识库”**（不存在的角色那题），违反“正文不提库”的约定。只见到一次。
6. **“读了 N 篇”偏大**：检索结果里列出的原文行也算，一次检索就能让这个数到十几。口径是开发者定的，记一笔。
7. **“回到底部”按钮盖住正文右缘**两三行的行尾（`ai_chat_page.dart`，`scroll-to-bottom`）。开发者说过这轮不改；要改先问想要的样子。

### 已知、暂不处理

8. 出处只核对“看没看过”，不核对那几行是否支持那句话（编造、张冠李戴、接受提问里的错误前提）。审稿默认关，是开发者的决定。
9. 模型输出里的杂质（混入外文词、把名字写错一个字）没有检查。GLM 在“思考”关着时仍会输出英文的思考文字，界面照样显示。
10. 安装脚本 `tools/install_local.ps1` 最后“自动打开 App”一步在 PowerShell 5.1 下总是报失败（adb 的普通输出被当成错误），安装本身是成功的。
    同样的原因：调这个脚本时不要加 `2>&1`，否则 `adb push` 之后脚本会中止。

### 把本机构建的知识库装到手机上

App 只认校验值与构建时写进去的一致的库，所以要连包一起装：

1. 把两个 `.gz` 的 SHA-256 临时写进 `tools/release_gamedata.env`，`install_local.ps1 -Build -Bridge`，**构建完立刻还原这个文件**（不提交）。
2. `adb push` 两个 gz 到 `/sdcard/Android/data/com.arklores.arklores/files/`，文件名 `arklores_gamedata_zh.db.download.gz`、`arklores_endfield_zh.db.download.gz`。
3. 推送**完成后**再让开发者在知识库页点“更新”。推送中途点了，App 会去下载旧资产、校验不过、把文件删掉，要重推。
4. 装好后同目录下的 `.asset_sha256` 标记应等于新的 SHA。

### 桥能看到什么

`tools/phone_ask.dart` 通过 `lib/features/ai/phone_bridge.dart` 拿到的是 App 的问答状态，不是屏幕。

- **可以信终端的**：步骤的种类、顺序、参数；思考文字；状态行；最终答案的文字和出处；用量一行；汇总行（“已作答 · 查阅 N 次 · 读了 N 篇”）。
- **终端看不到的**：出处卡（故事名有没有解析出来、能不能点开）、底部“证据 N 处 · 来自 N 个故事”、答案的排版与折叠、
  思考面板的样子（固定高度是既有设计）、状态行停留多久、滚动行为。
- **界面上几个数的数法**：“查阅”= 全部工具调用，含拟定的检索；“证据 N 处”把同一篇里重叠的行段并成一处，资料算在内；
  “来自 N 个故事”指故事集，不是故事文件。所以它们和答案里不同出处的条数对不上是正常的。
- 检索内部各段的耗时在会话记录的 `timeline` 里（`search:keywords:*` 等），是 App 自己记的，不经过桥。

## 8. 接手时要知道的做法

- 花钱的事（真实 API、向量嵌入）先问开发者；每个方面最多 2 个用例，逐题串行，看完一题再跑下一题。
- 电脑上的 live 测试（`test/live/ask_pipeline_live_test.dart`）不是真机测试，汇报时要分清。
- 嵌入：先 `build_story_embeddings.dart --dry-run`；明日方舟的库一定带 `--migrate-from=<有向量的旧库>`（不带会重嵌入五万多块，约 ¥5），
  且旧库不能和 `--db` 是同一个文件，先复制一份。
- 提交：作者只有 hhikr，不加任何 AI 署名；提交前 `git checkout -- android/gradle.properties`。
- PowerShell 5.1：含中文弯引号（“ ”）的字符串会被当成引号截断，改这类文本用编辑工具或脚本文件；
  `Set-Content -Encoding utf8` 会写 BOM，提交信息文件用 Python 或 `[IO.File]::WriteAllText` 写。
- 改提示词时：每条规则只在一处（`lore_agent_prompts.dart` 的各节），不放具体人物/章节名，有守卫测试。
- 调查笔记、探针脚本放 `notes/`、`test/live/scratch/`（都不进仓库）。
