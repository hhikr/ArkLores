# ArkLores：怎么用？

首先，请稍微读一读[这个](INTRODUCTION.md)，了解一下Arklores的大致功能。

这篇从安装写到提问。上一篇放了很多动图，这篇不再配图，按 App 里按钮和页面的名字来写，打开 App 对着找就行。现在的版本是 1.0.0，目前只有 Android 版。

## 怎么装

App 和知识库都放在 GitHub Releases：

https://github.com/hhikr/ArkLores/releases

1. 在最新版本下面下载 `ArkLores-1.0.0.apk`。
2. 在手机上打开这个文件，按系统提示允许安装。
3. 第一次打开 App，按新用户导览配置（见下一节）。

说明：之后的新版本可以在“设置 → 帮助与引导”里点“检查更新”，下载完会直接打开安装界面。打开“自动检查更新”后，每天第一次打开 App 时检查一次，不会自己下载。

注意：11 月 14 日装过 1.0.0 的，在 App 里检查不到 11 月 15 日的新 APK（版本号一样）。想用泰拉年表，请回发布页重新下载 APK 覆盖安装，原来的设置和知识库都会保留。

## 第一次打开：新用户导览

第一次打开 App 会进入新用户导览，一页一步：

- 外观：选主题（跟随系统、日间、夜间）和阅读字体（黑体或霞鹜文楷）。
- 资料设置：填你的称呼。剧情里的“博士”会显示成这个名字，不填就是“Dr.博士”。
- 配置问答 AI API：填对话 API，见下一节。
- 向量 API：可以不填，但问答质量会明显下降，见下一节。
- 知识库：下载明日方舟和终末地的知识库。
- 剧情美术：下载剧情美术包。
- Wiki 站点：Wiki 页显示哪些站点，问答也从这些站点查资料。
- 权限请求：允许通知和不受电池优化限制（部分手机才有这一步）。

每一步都可以先跳过，之后在设置里补上。想重新走一遍，在“设置 → 帮助与引导 → 新用户导览”。

## 准备两个 API

AI 问答要两个 API，在导览里填，或者之后在“设置 → AI 服务 → API 设置”里填。每个都是 URL、API KEY、MODEL 三项。

ArkLores 没有自己的服务器。查知识库和 Wiki，再核对出处，这些都在你的手机上做，只有模型推理交给你填的服务商，费用也由服务商直接向你收。

### 对话 API：用来推理和写答案

推荐智谱的 `glm-5.3-flash`，我几乎所有测试都是用它跑的。

1. 在智谱开放平台注册账号，新建一个 API Key。
2. 把 Key 填进“API KEY”。
3. MODEL 保持 `glm-5.3-flash`。
4. 检查 URL：默认是 `https://api.z.ai/api/paas/v4`（智谱国际站）。在国内站（bigmodel.cn）注册的，改成 `https://open.bigmodel.cn/api/paas/v4`。
5. 点“保存配置”。

说明：别家服务商只要兼容 OpenAI 的接口格式也能用，填它的 URL、Key 和模型名即可。但我基本没测过别的模型，效果不保证。

### 向量 API：用来按意思找剧情

问答查资料时，要把问题转成向量，才能按意思找到相关的剧情，而不只是字面相同的句子。资料页的“按意思找剧情”也靠它。

1. 在阿里云百炼开通服务，新建一个 API Key。
2. 把 Key 填进向量部分的“API KEY”。
3. URL 和 MODEL 不用改，默认就是百炼的地址和 `qwen3.7-text-embedding`。
4. 点“保存配置”。

注意：模型必须是 `qwen3.7-text-embedding`。知识库里现成的剧情向量是用这个模型算的，换成别的模型，两边的向量对不上，按意思检索就用不了。

说明：向量非常便宜。日常提问只需要把问题本身转成向量，两三块钱能用很久。只有在 App 里自己更新知识库、或者把个人资料加进问答时，才要多算一些向量。

## 下载知识库和剧情美术包

资料页和 AI 问答都靠知识库。在导览里下载，或者到“设置 → 知识库与资料 → 知识库管理”。

1. 在“明日方舟”页的知识库卡片上点“下载”。
2. 等它下载完，再等校验和解压。解压时不要退出 App。
3. 想看终末地的剧情，切到“终末地”页，同样点“下载”。
4. 在“明日方舟”页的“剧情美术”卡片上，选标准版或高清版，点“下载”。

明日方舟库压缩后约 129 MB，终末地库约 16 MB，美术包可以不装。

注意：下载知识库前，手机要留出约 1 GB 空闲空间。有的网络连 GitHub 的下载地址会卡住，App 里有超时和重试，已经下载的部分会保留，再点“更新”会从断点接着下。实在下不动可以换个网络试试。

说明：

- 剧情美术包只有明日方舟有，包括立绘、场景背景、CG 和特写。标准版约 400 MB，高清版约 800 MB，两个都装了时选一个用。不装美术包也能读剧情，只是没有图。
- 知识库管理页下面的“用游戏数据更新”是在手机上自己构建知识库，一般用不到。完整重建时，新库不带向量，要用你的向量 API 重新算，有费用。

### 知识库更新

明日方舟的数据来自社区解包仓库 Kengxxiao/ArknightsGameData。服务器每小时检查一次解包仓库，有新内容就自动更新知识库和美术包，App 启动或回到前台时会提示。终末地的库从 1.0 起也由服务器自动更新，数据取自 GitHub 上的终末地数据仓库，一般比游戏晚几天到一周。

看到“知识库有更新”的弹窗时，点“去更新”就会进入知识库页，在对应的卡片上点“更新”。

### 让问答在后台继续

一次问答至少要几分钟。有些系统（比如 ColorOS）在你切到别的 App 几秒后就会冻结后台，问答会因此中断。

1. 打开导览里的“权限请求”一步，或者在 App 提示时点“去允许”。
2. 允许“通知”。
3. 允许“不受电池优化限制”。

允许后，问答和下载进行时会一直在后台运行，通知栏会显示进度。

## 资料页：读剧情

资料页顶部有三个标签：明日方舟、终末地、补充资料。

### 找到要读的剧情

- 书架的第一行是泰拉年表（明日方舟），按纪元、世纪、年份列出剧情里的事件。可以筛选，出处对得上剧情的，点一下就进阅读器。
- 下面是各个书架：主线、SideStory、故事集、干员、集成战略、生息演算、图鉴等。故事集可以按时间或字数排序。
- “继续阅读”是你最近读过的剧情，点一下回到上次读到的那一行。
- 搜索可以找章节、条目和关卡代号，也会搜正文。配了向量 API 后，还能“按意思找剧情”。

### 在阅读器里

- 点屏幕：唤出工具栏，有目录、在本篇中查找、人名下划线开关等。
- 点顶部标题：展开进度条，拖动可以跳到这一章的任意一行。
- 章节开头的“官方梗概”默认收起，点开再看，避免剧透。
- 装了剧情美术包后，场景和 CG 会排在对应的对话之间，点开可以全屏看。

### 人名下划线和立绘卡片

在剧情和 AI 回答里，作为说话人出场、有立绘的名字会加下划线。

- 点下划线：旁边弹出小卡片，显示这个人的立绘。
- 点小卡片上的“更多”：打开立绘卡片，看所有服装和表情差分，还有谁也用过这个立绘、这个人用过哪些立绘。
- 在回答里长按下划线：屏蔽这个词，以后不再加下划线。屏蔽过的词在“设置 → AI 服务 → 下划线屏蔽词”里，可以取消。

说明：下划线是按名字匹配的，会误标一些词，比如“学生”“贵族”，或者地名里碰巧包含的人名。遇到就长按屏蔽。不想看干员名字的下划线，可以打开“回答里不标干员名”。

### 剧情美术总览

明日方舟页的书架里有“剧情美术”，可以按人物、图名或故事集搜索所有立绘、背景和 CG。为了防剧透，剧情美术默认按组收起，想全部展开可以在设置里改。

### 终末地

终末地有一个单独的库。干员这边有档案、语音和干员情报，另外有情报档案库，敌人、武器、物品描述，以及全部剧情对话和过场台词。

书架按游戏任务面板分成主线、探索、支线、活动和委派任务。一个任务是一篇剧情，按任务步骤排列，每段对话放在游戏里播放它的那一步，步骤目标当小标题。这个顺序是从关卡数据推出来的，大部分对得上，也有放错的。大约两成对话从数据里定不出位置，统一放在每篇末尾的“未定位的对话”下，默认收起。

问答每次两个游戏都会查。

## Wiki 页

Wiki 页可以直接浏览 PRTS 和终末地的 Wiki，顶部标签切换站点。页面工具里可以加书签、切换页面深色、放大或缩小文字。

想换站点或者加别的 Wiki，在“设置 → 知识库与资料 → Wiki 来源”里修改。改完马上生效，问答查 Wiki 时也会用新的站点。

## AI 问答

### 提问

1. 在 AI 页的输入框里写问题。
2. 点输入框旁的选项按钮，打开“回答选项”，按需要开关：
   - Wiki 资料：联网查 PRTS 或 Warfarin，出处会写明。默认打开。
   - 深度思考：写答案前先思考，更慢、更费 token。默认打开。
   - 子助手：问题很宽时并行检索，花费明显增加。默认关闭。
3. 点“发送”。

一次问答要几分钟。期间可以切去读剧情，也可以在左上角的对话栏开新对话，几个对话可以同时在后台作答。想中途停下，点停止，正在等的模型请求会马上断开，不会在后台继续跑。

### 怎么问效果好

- 一次问一件事。想知道好几件事，分几次问，或者在同一个对话里追问。
- 名字写你记得的叫法就行，代号、外号都可以，AI 会自己去查是谁。
- 想核对某个说法，直接问“某某是不是某某”。答案会给出核查结论：支持、反驳、存疑或无法确认。
- 追问时直接在同一个对话里接着问，AI 会先重读上一个答案引用过的原文。

### 看答案

- 答案上方有状态：“已作答”“可能有遗漏”或“没有找到原文”。“可能有遗漏”表示 AI 自己说明了哪些没查到或没读完，答案末尾会逐项写明。
- 每个论点后面有出处标签，点开就跳到那段原文，读完点“回到引用处”。出处也可能是泰拉年表或官方梗概，答案里会标明，比如“据泰拉年表”“据官方梗概”。Wiki 页面和补充资料也能作出处。
- 答案里可以展开工作过程，看 AI 每一步查了什么、读了哪些原文。
- 答案下面有两个按钮：
  - 提要：在答案上方加几段提要，详细经过折叠在下面，多一次调用。
  - 复核：另一个模型以读者身份对答案提出疑问，回原文核实后重新作答，多几次调用。

### 费用和长对话

- 想知道每一问花了多少钱，在“设置 → AI 服务 → 回答价格”里填你的模型服务的输入、输出价格。之后每个答案下面会显示这一问的费用。
- 一个对话聊得越久，上下文越长，每一步越贵，模型也越容易漏看前面的内容。超过“上下文提醒值”时，App 会提醒你，这时开个新对话接着问比较好。
- 打开“设置 → AI 服务 → 保存 AI 对话记录”，以前的对话可以在“对话记录”里找回、接着问。

## 补充资料：让 AI 参考你自己的资料

资料页的第三页是补充资料，预置了《大地巡旅》。问答会检索它的全文，资料页里只显示答案引用到的段落。你也可以导入自己的 Markdown 或文本笔记，选它参与问答，比如官方在社交平台发的补充内容。

添加个人资料：

1. 在“补充资料”里点“新建”“导入文件”或“粘贴文字”。导入的文件要是 UTF-8 编码的 Markdown 或纯文本。
2. 填标题和正文，点“保存”。
3. 打开“来源说明”，写内容种类，以及来源、作者是谁、适用范围和局限。
4. 打开“参与问答”。

注意：启用的这些笔记会发给你配置的向量服务建立索引，要先配好向量 API。状态变成“已就绪”后，下一问开始生效。

说明：来源说明是给 AI 解释这份资料的，不会让 AI 直接把它当真。说明写得太简略、内容又和原文对不上，即使你写了“最高优先级”，AI 也会提出质疑。

## 常见问题

**问答切到后台就停了？**
按上文“让问答在后台继续”允许不受电池优化限制。

**不配向量 API 能用吗？**
能用。问答只用关键词检索，质量会明显下降。资料页的普通搜索不受影响。

**Wiki 页打不开？**
看错误提示。“无法解析 Wiki 域名”一般是网络、DNS 或代理的问题，“连接超时”可以稍后重试。

**AI 说的一定对吗？**
不一定。答案里的每个论点都附了出处，请点开原文自己判断。上一篇文末写了我对 AI 功能的看法，这里不再重复。
