# 补充资料与问答

资料页的“补充资料”管理预置读物和个人文本。开启“参与问答”后，Ask 在同一次检索中查找两个游戏知识库、补充资料和已开启的 Wiki；不需要从某篇资料进入问答。

## 使用

《大地巡旅》随应用提供完整正文和匹配当前默认向量模型的索引，默认开启。个人资料可新建、粘贴或导入 UTF-8 Markdown／文本，默认关闭。开启后，正文会发送给设置中配置的向量服务；保存修改时只重新处理变化的检索块。资料页显示就绪、待更新、索引中和失败状态，可取消或重试。

没有向量服务、模型不匹配或建立失败时，资料仍能阅读，问答可以按关键词检索。待更新不代表语义索引已完整；正文修改后的旧向量不会被用于新内容。未变化的块继续可用。

资料选择、正文版本和来源说明在每次发问时固定，修改从下一问生效。关闭的资料不再供本轮之后的检索与读取使用。已有答案的出处仍能打开对应历史版本。

## 来源说明

每份资料可以填写内容种类，以及作者、叙述视角、适用范围和认识局限。说明帮助模型解释正文，不是正文已经正确的证明，也不作为正文引用。

本书的预设说明区分埃里克森叙述与已确认的凯尔希批注。认知等级是用户配置的解释规则；批注的补充、评价不自动等同于纠正。无法从输入资料确认作者或类别的段落保留未知状态。

## 检索与引用

全文保存在独立的资料数据库中，版本与向量分别保存。检索块沿标题、段落和作者边界划分，约 800 字符；超长段落继续分片，不删除后文。向量以嵌入文本摘要、模型和维度复用。

`search`、`grep`、`gather` 同时覆盖已启用的补充资料。`read_material` 按文档、版本及段号读取；`search(near)` 可以在游戏剧情与补充资料之间查找相似段落。`guide` 说明可用来源，`sql(source="materials")` 只查询本轮启用资料的两张快照表，不连接用户数据库。查询保留只读检查和超时中断。

引用格式为 `material:<文档ID>@<版本>:<起始段>-<结束段>`。只有工具实际展示的段落登记为已读；只查到目录或来源说明不算读过正文。出处核对仍不等于证明引用支持结论。

## 维护预置资料

`tools/build_materials.dart` 接收正式 Markdown 目录，可在构建时读取区域类别映射。导航只生成目录，不进入正文；校对记录、审批、扫描坐标与本机路径不进入预置包或向量输入。

先使用 `--dry-run` 检查文档、段落、检索块和预计用量，再按项目费用约定建立索引。构建复用本地缓存，只有完整匹配的向量全部存在时才生成 `assets/materials/terra.json.gz`。此文件随 APK 分发，游戏知识库的发布与更新流程保持独立。
